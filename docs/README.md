## Criterios del proyecto
Eldoria se construye por etapas pequeñas y verificables. Las decisiones narrativas y jugables se documentan antes de implementarse para evitar rehacer sistemas centrales.

La prioridad técnica es un mundo 3D persistente, modular y de rendimiento razonable en PC modestas y Android. La identidad visual será de fantasía estilizada, con lectura clara y variedad lograda mediante composición y materiales eficientes.
